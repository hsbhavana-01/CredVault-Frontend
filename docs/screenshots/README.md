# Live application screenshots

Capture the running Task 4 application in a browser and place the screenshots in this folder. Use real records created through the app, not sample or placeholder records. Suggested filenames: `home.png`, `request-success.png`, `track-result.png`, `verify-result.png`, `admin-login.png`, `admin-applications.png`, and `admin-certificates.png`.

Then embed them in the root `README.md` using relative Markdown image paths, for example `![Home page](docs/screenshots/home.png)`. Do this after running both the frontend and backend locally.
